### 🔹 Java Streams API  
Experiência prática com processamento funcional de coleções:

- `stream()` – criação de streams  
- `filter()` – filtragem de dados  
- `map()` – transformação de dados  
- `forEach()` – iteração  
- `collect()` – conversão de stream para lista  
- `flatMap()` – manipulação de listas aninhadas  
- `reduce()` – agregação de valores  

📌 Exemplos aplicados:
- Filtrar valores com base em regras de negócio  
- Aplicar cálculos (ex: aumento/desconto) com `map`  
- Transformar listas em novos formatos  
- Trabalhar com dados encadeando operações
